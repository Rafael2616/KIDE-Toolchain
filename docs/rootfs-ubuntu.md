# Ubuntu RootFS

O KIDE utiliza a base do Ubuntu (Ubuntu Base) para fornecer um ecossistema Linux familiar e compatível com as ferramentas de desenvolvimento modernas.

## 📦 Download da Imagem Base

A imagem utilizada atualmente é a **Ubuntu 22.04.5 (Jammy Jellyfish)**.

*   **Página de Downloads:** [Ubuntu Base Releases](https://cdimage.ubuntu.com/ubuntu-base/releases/22.04.5/release/)

### Arquivos Recomendados
Para uso no KIDE, prefira os arquivos compactados (`.tar.gz`) específicos para a sua arquitetura:
- `ubuntu-base-22.04.5-base-arm64.tar.gz` (Para dispositivos Android modernos)
- `ubuntu-base-22.04.5-base-amd64.tar.gz` (Para emuladores e PCs)

---
> [!NOTE]
> Esta imagem é minimalista e não contém interface gráfica por padrão, sendo ideal para o backend do KIDE.
