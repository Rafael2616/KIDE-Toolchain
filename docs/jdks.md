# Java Development Kits (JDKs)

Esta página lista os links de download oficiais para as versões do Java utilizadas no KIDE Toolchain. As versões são obtidas via Adoptium (Eclipse Temurin).

## ☕ JDK 17 (LTS)

Versão estável recomendada para a maioria das ferramentas de build Android.

| Arquitetura | SO | Download Link |
| :--- | :--- | :--- |
| **ARM 32-bit** | Linux | [Download](https://api.adoptium.net/v3/binary/latest/17/ga/linux/arm/jdk/hotspot/normal/eclipse) |
| **AArch64** | Linux | [Download](https://api.adoptium.net/v3/binary/latest/17/ga/linux/aarch64/jdk/hotspot/normal/eclipse) |
| **x64** | Linux | [Download](https://api.adoptium.net/v3/binary/latest/17/ga/linux/x64/jdk/hotspot/normal/eclipse) |
